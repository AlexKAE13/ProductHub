# Product HUB

Внутреннее веб-приложение Eltex: база знаний по продуктам (SKU) и база артефактов отдела.
Полное ТЗ - в `SPEC.md`, правила разработки - в `CLAUDE.md`, текущее состояние - в `STATUS.md`.

## Что нужно на Mac

Нужна Java 21 (JDK). Maven ставить не обязательно: в проекте есть `./mvnw`.

```bash
brew install openjdk@21
```

Homebrew не подключает эту Java к системе сам. Чтобы `./mvnw` ее нашел, выполните один раз в терминале
(или добавьте строку в `~/.zshrc`):

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21
```

Проверка:

```bash
$JAVA_HOME/bin/java -version
```

Должно показать `openjdk version "21...`.

## Запуск

```bash
./mvnw spring-boot:run
```

Откройте http://localhost:8080. Откроется страница выбора тестового пользователя (режим разработки).
Переключить пользователя можно в любой момент списком "Войти как" в шапке.

## Работа по локальной сети (коллеги открывают ваш компьютер)

1. Запустите приложение с профилем `lan` (в нем тестовые учетные записи скрыты, виден список коллег):

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@21 && SPRING_PROFILES_ACTIVE=dev,lan ./mvnw spring-boot:run
```

2. Узнайте адрес своего компьютера в сети:

```bash
ipconfig getifaddr en0
```

3. Коллеги открывают в браузере `http://<этот адрес>:7777` (в профиле `lan` приложение слушает порт 7777), выбирают свое имя и работают. Если macOS спросит про входящие подключения, разрешите.
4. На время работы компьютер не должен засыпать (Системные настройки - Экран - не отключать при питании от сети). Пароля нет, поэтому открывайте приложение только в доверенной сети отдела.

Комментарии к интерфейсу: на каждой странице справа внизу кнопка "Комментарий". Нажать, выбрать элемент, написать. Файл со всеми правками выгружается в пункте меню "Правки" кнопкой "Выгрузить файл" и передается разработчику.

Папка сборки называется `target.nosync`: так iCloud ее не синхронизирует. Если проект лежит в папке, синхронизируемой iCloud, советуем перенести его в обычную папку (например `~/Projects`), иначе возможны зависания.

## Установка на сервере компании

Инструкция для ИТ: [docs/deploy.md](docs/deploy.md) (Docker Compose: приложение + PostgreSQL, вход через AD/LDAP, бэкап и восстановление, перенос данных из пилота).

Тесты на PostgreSQL (Testcontainers) требуют Docker. На Mac с Colima перед `./mvnw verify`:

```bash
export DOCKER_HOST=unix://$HOME/.colima/default/docker.sock
export TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE=/var/run/docker.sock
```

Без Docker эти тесты пропускаются.

## Тесты и проверка

```bash
./mvnw verify
```

## Локальные данные

База H2, файлы и индекс поиска лежат в папке `./data`. Чтобы начать с чистого листа, остановите приложение
и удалите папку:

```bash
rm -rf ./data
```

## Профили

- `dev` (по умолчанию): база H2 в `./data`, переключатель "войти как".
- `prod`: PostgreSQL, настройки из переменных окружения (см. `.env.example`), вход через AD/LDAP.
- `lan`: добавляется к dev при работе по локальной сети, скрывает тестовые учетные записи.
- `perf`: данные для замера скорости (отдельная база в `./data-perf`).

```bash
java -jar target/product-hub-0.1.0-SNAPSHOT.jar --spring.profiles.active=prod
```
